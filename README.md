# Solitaire

Classic Klondike solitaire as an installable web app. Tap a card to send it to the best spot, or drag it. Draw 1 or draw 3, undo, auto-finish, and offline play.

- Play: https://nicholasemccormick.github.io/solitaire/
- Install on iPhone: open the link in Safari, tap Share, then Add to Home Screen.

Served by GitHub Pages from the `gh-pages` branch.
